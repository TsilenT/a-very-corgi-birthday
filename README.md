# A Very Corgi Birthday

Pip the corgi has an afternoon to bake a cake, buy and inflate balloons, and get the house ready for Camille. Finish the party to hear Pip sing Happy Birthday.

[Play the game](https://acorgibirthday.stevets.ai)

Tap or click the actions to play. On a keyboard, use the numbers shown beside the actions. Tap Pip to see what he gets up to. The game saves your progress and sound preference in this browser.

The project uses static HTML, CSS, and JavaScript. Serve this directory with any static development server. GitHub Pages publishes the root of `main` at the hostname in `CNAME`.
